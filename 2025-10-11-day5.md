## 1) What I learned (bullets, not prose)
- There are different kinds of data: tabular, semi-structured (like JSON or graphs), and unstructured (like photos or videos).
- CSV is easy to read but heavy, JSON is flexible but can have duplicates, and Parquet/ORC are efficient and compressed.
- Pick the data format based on what you need, not what’s easiest.
- UV helps manage Python packages and keeps installations isolated.
- Pandas is great for small datasets and beginners, but not for huge files since it loads everything into memory.
- Ibis can connect to many databases with one simple API.
- APIs let machines talk to each other — we can pull data automatically instead of manually.
- Web scraping means collecting data from websites using tools like BeautifulSoup.
- If the site is static, use BeautifulSoup; if it’s dynamic (like Lazada), use a headless browser like Playwright.
- Be ethical. Not all data on the internet is free to scrape.

## 2) New vocabulary (define in your own words)
- **UV** - A Python package manager that keeps your environment clean and organized.
- **Ibis** - A tool that connects Python to databases easily.
- **API** - A way for two programs to share data with each other.
- **BeautifulSoup** - A Python library to help get data out of HTML pages.
- **Headless browser** - A browser that runs without showing anything on screen, used for scraping sites that need JavaScript.

## 3) Data Engineering mindset applied (what principles did I use?)
- Always pick the format that fits the purpose, not just the easiest one
- Always check data quality and think about ethics when collecting data.
